# Percentage Calculations Explained with Everyday Examples

Percentages appear in shopping discounts, exam scores, salary changes, business reports, taxes, interest rates, and statistics. The word **percent** means "per hundred", so a percentage expresses a value as a fraction of 100.

Once you understand a few formulas, many percentage problems become straightforward. The [iamnoobs Percentage Calculator](https://iamnoobs.com/percentage-calculator) can help calculate common percentage values, increases, and decreases.

## What does percentage mean?

A percentage represents a ratio out of 100.

For example:

~~~text
25% = 25 / 100 = 0.25
~~~

Therefore, 25% of 200 is:

~~~text
200 × 0.25 = 50
~~~

A percentage is not a unit of measurement. It describes how one value relates to another.

## Calculate a percentage of a number

Use this formula:

~~~text
Percentage value = (Percentage / 100) × Total
~~~

Example: What is 18% of 750?

~~~text
(18 / 100) × 750
= 0.18 × 750
= 135
~~~

So, 18% of 750 is 135.

## Find what percentage one number is of another

Use this formula:

~~~text
Percentage = (Part / Whole) × 100
~~~

Example: A student scores 72 marks out of 90. What is the percentage?

~~~text
(72 / 90) × 100 = 80%
~~~

The score is 80%.

The whole must be the correct reference value. If the maximum possible marks change, the percentage changes too.

## Calculate percentage increase

Percentage increase measures how much a value has risen relative to its original value.

~~~text
Percentage increase =
((New value - Original value) / Original value) × 100
~~~

Example: A monthly subscription increases from 400 to 460.

~~~text
Difference = 460 - 400 = 60

Percentage increase = (60 / 400) × 100
                    = 15%
~~~

The price increased by 15%.

## Calculate percentage decrease

Percentage decrease measures how much a value has fallen relative to its original value.

~~~text
Percentage decrease =
((Original value - New value) / Original value) × 100
~~~

Example: A product price falls from 1,200 to 900.

~~~text
Difference = 1,200 - 900 = 300

Percentage decrease = (300 / 1,200) × 100
                    = 25%
~~~

The price decreased by 25%.

## Understand percentage points

Percentage change and percentage-point change are not the same.

Suppose an interest rate rises from 5% to 7%.

- The absolute change is 2 percentage points.
- The relative percentage increase is (2 / 5) × 100 = 40%.

This distinction matters when reading financial, economic, and statistical reports.

## Everyday examples

### Shopping discount

A product costs 2,000 and has a 15% discount.

~~~text
Discount = 2,000 × 0.15 = 300
Final price = 2,000 - 300 = 1,700
~~~

The final price before any additional taxes or fees is 1,700.

### Salary increase

A salary changes from 600,000 to 660,000 per year.

~~~text
Increase = 660,000 - 600,000 = 60,000
Percentage increase = (60,000 / 600,000) × 100
                    = 10%
~~~

The increase is 10%.

### Exam result

A student gets 425 marks out of 500.

~~~text
(425 / 500) × 100 = 85%
~~~

The result is 85%.

## Repeated percentage changes

Successive percentage changes are applied to the changing value, not always to the original value.

For example, a 10% increase followed by a 10% decrease does not return to the starting value.

Start with 100:

~~~text
After 10% increase: 100 × 1.10 = 110
After 10% decrease: 110 × 0.90 = 99
~~~

The final result is 99, which is 1% lower than the starting value.

## Common percentage mistakes

### 1. Using the wrong base value

The denominator in a percentage calculation matters. For an increase, use the original value as the base, not the new value.

### 2. Confusing percentage points with percentage change

A movement from 20% to 25% is a five-percentage-point increase and a 25% relative increase.

### 3. Adding successive discounts directly

A 20% discount followed by another 10% discount is not always a total 30% discount. The second discount is often applied to the already reduced price.

### 4. Ignoring rounding

Rounding can create small differences in totals, especially in invoices, taxes, and financial calculations. Follow the applicable rules for the task.

### 5. Dividing by zero

A percentage change from an original value of zero is undefined under the usual formula because the calculation requires division by the original value.

## Frequently asked questions

### How do I convert a fraction to a percentage?

Divide the numerator by the denominator and multiply the result by 100. For example, 3/4 = 0.75 = 75%.

### Can a percentage be greater than 100%?

Yes. A value of 150% means 1.5 times the reference value. It can occur in growth rates, comparisons, and ratios.

### What does a negative percentage change mean?

A negative change indicates a decrease relative to the chosen base value. Always state the original and new values so the direction is clear.
